How it works

The model drafts with noise and verifies with itself

Uno keeps the base model frozen and adds one LoRA that is switched on only for noise positions. Each decode step drafts a block of 8 positions in one forward, then the unmodified model verifies them and keeps the longest correct prefix. The first position is always the exact AR token, so a step never moves backward.

Training is self-distillation

Each sequence appears twice in one batch: a clean copy (frozen model, the teacher) and a block-noised copy (model + LoRA, the student). The loss is the total-variation distance between the two next-token distributions on the response tokens. Acceptance probability under lossless verification is exactly 1 − TV, so the loss trains the quantity decoding cares about. Dataset labels are never used; the data only supplies realistic contexts.

Why the looped model fits

Nanbeige4.2-3B runs its 22 layers twice per token. At decode time it reads weights like a ~6.3B model, so it costs as much per step as Qwen3-8B (28.8 ms each). Drafting more tokens per step is where a looped model gains the most, and the LoRA trains through both loops with no change to the recipe beyond ZeRO-0 for the shared weights.

With lr 1e-4 most of the gain arrives in the first hour: TPF 2.04 at 52 min, then 2.18 after 3.5 h. lr 1e-5 needs ~4 h to reach the same point. Both curves flatten near 2.1–2.2, which is a per-position acceptance of about 0.54 (Qwen3-8B Uno reaches 0.64 after 14.7B tokens).

Uno pays for itself once TPF passes ~1.3. From one hour on, decoding is 1.4–1.5× faster end to end. The gap to the per-step estimate (~1.6–1.7×) comes from the long tail of each batch, when a few long sequences keep the GPUs underfilled; single 200-problem timings vary by about ±10%.

Limits and next steps

What this does not show yet

  • Benchmark scope. Agentic results replay recorded trajectories and score single function-calling turns; a full closed-loop agent run (environment execution, multi-turn tool feedback) is still to do.
  • Sample size. 200 problems per point; full 1319-problem runs will tighten the end-to-end timings.
  • The plateau. TPF stops near 2.2. The training data was written by other models, while the drafter is scored against Nanbeige's own continuations; training on Nanbeige's self-generated responses is the first fix to test.
  • Cheaper drafts. Drafting with one loop instead of two halves the draft cost.
